# 平时用过设计模式吗？怎么用？

用过挺多的，最主要就是策略+工厂+模板方法吧，我相信大部分支付中台都有类似的用法：就是会根据不同的支付渠道，选用不同的策略来做下单逻辑，同时下单方法也大多有一个模板，比如先预下单，然后再进行订单落库，最后再正式下单。

# 单例模式

## 懒汉模式

被用到的时候才进行初始化：

- volatile修饰属性类
- 先判断是否已实例化，有的话直接返回
- 没有：
    - 先synchronized上锁
    - 再判断一次是否已实例化，有的话直接返回（**双重锁定，防止所有在等待锁的线程都实例化一次**）
    - 没有则实例化

## 饿汉模式
